# VOLTERA EV Charging Platform

VOLTERA is an EV Charging platform consisting of a Flutter Mobile Application and a Node.js TypeScript API Backend.

## 📂 Repository Structure

- [`voltera/`](file:///C:/Users/Shyam%20D.%20Thanki/Downloads/voltera/voltera) — Flutter Mobile Frontend App
- [`backend/`](file:///C:/Users/Shyam%20D.%20Thanki/Downloads/voltera/backend) — Node.js / Express / Prisma API Backend App

## 🚀 Quick Start Backend

```bash
cd backend
npm install
npm run prisma:migrate
npm run dev
```

Health check: `http://localhost:3000/health`
